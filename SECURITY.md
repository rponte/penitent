# Security policy

## Supported versions

Penitent is in `0.x`, so only the latest released version receives fixes.

## Reporting a vulnerability

Please do not open a public issue. Report it privately through GitHub, in the repository's **Security** tab, with
**Report a vulnerability**. Include what an attacker could do, the affected versions, and the steps to reproduce it.

The report is handled on a best-effort basis: it is acknowledged, and the fix and its disclosure are coordinated with
you through the advisory.
