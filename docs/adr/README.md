# Architecture decisions

The decisions that shape Penitent, each in a short record: the context, what was decided, what was measured to
back it, the alternatives left aside and the consequences. A record keeps the reasons next to the decision, so it can
be revisited when the context changes, instead of rediscovered.

Records are numbered in order and never renumbered. A decision that changes gets a new record that supersedes the
old one, which stays as history.
